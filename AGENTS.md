# AGENTS.md — правила для ИИ-агентов

Проект: решения 4 кейс-заданий по дисциплине «Этика в сфере
искусственного интеллекта» (полное название — «Искусственный интеллект,
большие данные и этика»), Университет «Синергия», группа ДМЭ-101цэии.
Продукт репозитория — 4 отчёта docx + pdf в `itog/`.

**Язык**: тексты, отчёты, коммит-сообщения и ответы обучающемуся — на
русском. Код и идентификаторы — на английском.

## Структура

```
assignments/keisy_etika_ii.md  тексты 4 кейс-заданий — read-only
cases/case-0N-*/content.py     содержимое отчёта кейса N (тексты, таблицы)
cases/case-0N-*/output/        собранный docx кейса N
templates/synergy_docx.py      движок стилей (копия big-data-labs +
                               параметр work_type; НЕ связан с оригиналом)
tools/build_reports.py         сборка docx (титул → СОДЕРЖАНИЕ → … → источники)
tools/convert_pdf.sh           docx -> pdf через soffice
itog/                          файлы сдачи: 4 docx + 4 pdf
REPORT_STANDARDS.md            локальный стандарт: база + надстройка кейсов
```

## Окружение и команды

- Сборка docx: `python3 tools/build_reports.py` (нужен python-docx).
- PDF: `tools/convert_pdf.sh` (нужен soffice на хосте; fallback — Docker,
  см. README «Сборка»).
- Полный цикл обновления СОДЕРЖАНИЯ:
  `build_reports.py` → `convert_pdf.sh` → `build_reports.py --update-toc`
  → `convert_pdf.sh` (номера страниц проставляются по фактическому PDF).
- Перед сдачей прогонять каждый docx через
  `../synergy-agent/scripts/sanitize_ooxml.py` и
  `../synergy-agent/scripts/validate_office.py`.

## Содержательные правила

- Единый источник содержимого — `cases/*/content.py`; НЕ править docx
  руками, только пересборка.
- Структура отчёта и схема «условие → анализ → таблица → Вывод:» —
  по `REPORT_STANDARDS.md` (раздел 2).
- Не выдумывать факты, цифры, номера статей и названия регламентов;
  все нормативные ссылки — проверяемые (152-ФЗ, 572-ФЗ, ТК РФ, ГК РФ,
  GDPR, Регламент (ЕС) 2024/1689, ГОСТ Р 59276-2020, ГОСТ Р 7.0.100-2018,
  ISO/IEC 24745, NIST AI RMF, C2PA, WHO 2021, Beauchamp/Childress,
  Mehrabi et al. 2021, US Copyright Office 2023).
- Каждая таблица имеет подпись «Таблица N — Название» и ссылку
  «(таблица N)» в тексте; нумерация сквозная.
